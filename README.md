# Stoneplan Patio Planner

[Open the live planner](https://frenchbear1.github.io/stoneplan-patio-planner/)

Plan the patio behind the shed using the measured inventory and actual stone textures.

- Start with a blank canvas or choose a saved patio design.
- Drag square, long, short, and edge blocks from the counted brick bank.
- Drag a box from empty canvas to select every block it touches. Hold Ctrl while clicking or drawing another box to add to the selection, then move or rotate the group together.
- Rotate individual blocks and snap nearby corners and edges together.
- Switch the magnet off for free placement.
- Choose photo textures or flat 2D colors.
- Save and reopen designs, undo changes, and print an installation map.

## Open locally

Open `index.html` in a modern browser. It contains the complete application and embedded photographs; no installation or build step is required.

See [USER_GUIDE.txt](USER_GUIDE.txt) for controls and dimensions. The `saved-designs` folder contains editable presets and printable maps. The `assets` folder contains the cleaned source textures used in the planner.

Designs are remembered in the current browser. Use **Save design** to keep a portable copy or send a layout to someone else.

## Publish updates

GitHub Pages publishes the root of the `main` branch. Updates to `index.html` become available at the live link after deployment finishes.
